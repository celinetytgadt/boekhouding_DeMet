# Documenten

Zet hier de afbeeldingen van de verantwoordingsstukken. De app zoekt ze
automatisch op bestandsnaam — er hoeft niets in de code aangepast te
worden.

**Naamgeving = referentie**, `.png` of `.jpg`:

- `Beginbalans.png` (of .jpg)
- `AK01.png` t/m `AK09.png`
- `VK01.png` t/m `VK05.png`
- `ONTV01.png`
- `DIV01.png` (loonsynthese)
- `BANK01.png` t/m `BANK05.png`
- `KAS01.png`
- `DIV02.png` (btw-verwerking)
- `DIV03.png` (afschrijvingstabel)
- `DIV04.png` (aflossingstabel)
- `DIV05.png` (voorraadbedrag/telling)

Eén document per afbeelding — geen pagina's met meerdere afschriften erop.

Ontbreekt een afbeelding, dan toont de app gewoon een duidelijke melding
in plaats van te crashen — je kan dus gerust in fases aanvullen.

Welk document als "laatste bankafschrift" en "laatste kasblad" gebruikt
wordt bij de controles (§7), stel je in bij `js/data-controles.js`
(`CONTROLE_CONFIG`).
